# Python Distilled - Study Notes

This repository contains study notes and code examples from **Python Distilled** by David M. Beazley.

## Book Information

- **Title**: Python Distilled
- **Author**: David M. Beazley
- **Publisher**: Pearson
- **ISBN**: 978-0-13-417327-6

## Chapters

- [Chapter 1: Python Basics](Chapter01.md) - Core Python concepts, syntax, and fundamentals
- [Chapter 2: Operators, Expressions, and Data Manipulation](Chapter02.md) - Operators, expressions, and data structures
- [Chapter 3: Program Structure and Control Flow](Chapter03.md) - Program structure, control flow, and exception handling
- [Chapter 4: Objects, Types and Protocols](Chapter04.md) - Object-oriented programming and type system
- [Chapter 5: Functions](Chapter05.md) - Function definitions, arguments, decorators, and functional programming
- [Chapter 6: Generators](Chapter06.md) - Generator functions, yield expressions, and iteration
- [Chapter 7: Classes and Object-Oriented Programming](Chapter07.md) - Classes, inheritance, and OOP concepts
- [Chapter 8: Modules and Packages](Chapter08.md) - Module system and package management
- [Chapter 9: Input and Output](Chapter09.md) - File I/O and data handling
- [Chapter 10: Built-in Functions and Standard Library](Chapter10.md) - Python's built-in functions and standard library

## Code Examples

Each chapter directory contains practical code examples and exercises from the book:

- `Chapter01/` - Basic Python examples including calculator, interest calculations, and portfolio management
- Additional chapter directories will be added as you progress through the book

## Getting Started

1. Clone this repository
2. Navigate to any chapter directory to explore code examples
3. Use the chapter markdown files to review key concepts and sections
